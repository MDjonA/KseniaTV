# KseniaTV

Бесплатное Android-приложение для Android TV и TV Box для удобного просмотра фильмов, мультфильмов и сериалов.

KseniaTV — это удобный видеоплеер и каталог для Smart TV. Интерфейс адаптирован под пульт, большие постеры и быструю навигацию.

### Возможности
- Удобный интерфейс для Android TV
- Каталог фильмов, мультфильмов и сериалов
- Поиск по названию
- Избранное и история просмотров
- Поддержка пультов и аэромыши
- Работает на Android TV, Google TV и TV Box
